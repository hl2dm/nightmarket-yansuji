## 一句話

## 新玩法循環
1. 客人到窗口 → 一張**夾單**夾上菜單夾(單上畫:客人自己撿的料=實心圖;要你補的料=虛線空圈,雞排/鹽酥雞一定是你補)。
2. 從展示櫃**把料拖到單上**(或直接拖進網子)補齊空圈。
3. **把整張單拖進油鍋**(或點一下單=自動下鍋,給手殘/行動裝置用)→ 自動分網:肉→大網、非肉→小網、雞排一塊獨佔一網;同網的料依炸的秒數相近分組,一網一位客人。
4. **鐵盆整個拿掉**。開局就有 4 網(2 大含 1 雞排網、2 小),升級到 6 網;第一位客人就能炸,可同時炸兩單。沒有空網時,單會彈回菜單夾。
5. 看料本身變色(生→金黃→焦黑),油泡變大變密、冒蒸氣、劈啪聲 → **把網子拖出油**到瀝油架。單塊快焦可用**夾子**單獨夾出(第 2 晚教)。
6. 瀝好的網**拖到托盤**倒出 → **拿調味罐在托盤上方拖曳搖晃**(胡椒鹽免費、辣粉 +$5、九層塔 +$3)。
7. **托盤拖進紙袋 → 紙袋拖到客人手上** → 客人遞錢,**把錢拖進錢箱**;阿姨殺價=拉扯鈔票的拖曳;開心客人會丟小費硬幣。
8. 付款 = 袋中每項售價加總(錢箱數字是畫面上少數保留的數字)。
9. 進貨 / 腐壞 / 每晚漲攤租 / 升級 / 口碑全部保留,改用實物表現:木箱(鮮/舊)、日曆紙(攤租)、紅燈籠串(口碑)、沙漏(營業時間)。

## 借鏡《魔龍寶冠》營地料理
- 直接用手把食材丟進鍋,沒有選單 → 我們:拖單/拖料進油鍋。
- 食物畫得很香,煮的過程本身就是資訊 → 每種料 3 張圖(生/金黃/焦)交叉淡入,加共用油泡、蒸氣、火花、黑煙特效。
- 時機靠眼睛和耳朵:冒黑煙=過頭 → 整鍋一條油炸聲,越接近熟音調越高;熟了「劈啪」、焦了「嘶—啪」。不用進度條。
- 攪拌加分 → 網子把手可左右甩一下讓上色均勻(選用加分)。
- 盛起、端上、吃掉的爽感 → 撈網、倒盤、搖粉、遞袋、收錢每步都有手感動畫和音效。
- 幾乎沒有 UI 外框 → 第一晚用「老闆的半透明手」示範,不用文字教學。
