# 阿恩鹽酥雞 — 台灣夜市攤位系列 #1(v3.2)

直接用瀏覽器開 `index.html` 即可(純 HTML5/JS,可放 GitHub Pages)。網址參數:`?seed=42`、`?speed=2`、`?autostart`。

## 玩法(一晚 3 分鐘)
客人點餐 → 點食材櫃(A–H)直接下到長方形油槽的 6 個方籃 → 油溫 Q/W/E → 每格熟度條轉綠「剛好!」按該格數字 1–6 撈起(空白鍵撈全部剛好的)→ 調味 Z/X/C、裝袋 Enter → 出餐收錢,面對殺價可「成交/讓價/堅持/拒絕」,可疑自備食材客可「🚨檢舉」。收攤後結算。

## 平衡說明
第一晚攤租 $500(設計稿為 $800,實測太苛,詳見 design.md 附錄)。

## 第二版:經營模式(多晚)
- 流程:標題 → 開攤前進貨 → 營業 → 收攤結算(付攤租、剩料報廢)→ 設備店 → 下一晚。
- 上方「菜單夾」:每位客人一張單(頭像、品項、辣/塔、倒數);綠/橘/紅代表耐心,櫃台那張是金框。
- 起始現金 $1000,攤租第 1 晚 $300、每晚 +$80;付不出會欠債(下晚 ×1.2),連兩晚付不出就 GAME OVER。
- 缺貨:客人點到沒貨的會出現「道歉換單 / 請客人離開」。
- 升級(大網、小網、冰箱、濾油機、霓虹招牌、電風扇、批發卡),每晚最多 2 項。油槽 8 格時鍵 1–8。
- 自動存檔在 localStorage `yansuji_save_v2`,標題畫面可「繼續」。
- 多晚自動試玩:`node ../_tools/multinight.mjs <晚數> <seed> <speed>`

## v40:先備料、整網一次炸、一次起鍋
- 點食材 = 放進「還沒下鍋」的網子(備料,虛線框+「備料 n/4 · 點網下鍋」)。同一單的小料優先放同一網;雞排一塊一大網。
- 點網子(或按 1–6,V = 備好的全下鍋)→ 整網一次下鍋;再點一次 / 空白鍵 → 整網一次撈到盤上。
- 每網只有一條共用熟度條:速度以網內最久的料為準(time 取最大、理想油溫取平均),共用「剛好」區 60–80;每份料的熟度由網的進度換算到自己的 lo–hi 區,所以綠色時撈,整網每份都剛好;紅色則整網一起焦。
- 移除網內每份料各自的熟度條/小字標籤。下鍋時才計油耗與降溫。
